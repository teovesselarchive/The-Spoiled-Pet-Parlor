# The Spoiled Pet Parlor

A complete interactive website concept with a playful, beauty-brand feel. Business name and **916-420-3244** are supplied by the owner. Services, location, hours, prices, policies and real customer imagery remain to be confirmed.

## Preview

Serve `dist/` with any static server. No package installation or build step is required:

```sh
python3 -m http.server 4173 --directory dist
```

Then open http://localhost:4173. You can also open `dist/index.html` directly; browser clipboard permissions may differ for local files.

## Included

- Responsive desktop, tablet and mobile layouts
- Three-question spa-day finder with back/reset states
- Service selection carried into the appointment wish list
- Required-name and future-date validation
- Preview, edit and copy a wish list; no requests are transmitted
- Accessible gallery dialog with Previous/Next, arrow keys, Escape and restored focus
- Expandable FAQs, mobile menu and a virtual dog boop
- Working click-to-call links
- Self-hosted fonts and responsive WebP campaign imagery
- Reduced-motion support, visible focus and semantic controls

## Files

`dist/index.html`, `dist/styles.css`, and `dist/app.js` are the editable website. `dist/assets/` contains self-hosted fonts and images. `source-images/` preserves original generated images. `DESIGN.md`, `RESEARCH.md`, `QA.md`, and `source-images/PROMPTS.md` record the creative direction, evidence, verification and image provenance.

## Launch requirements

The site is deliberately marked as a concept and noindex. Before a public business launch, confirm the real service menu, animal types, prices or quote policy, address, hours, first-visit requirements, actual booking destination and relevant privacy information. Replace illustrative imagery with approved real photography if desired. A live booking or lead-storage service has not been connected.

The planner keeps values only in the current page; no analytics, cookies, contact submission, database, accounts, or marketing subscription are installed.
